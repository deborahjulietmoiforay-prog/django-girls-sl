# Role-Based Access Control (RBAC)

This module defines user roles and permission policies across the community platform.

## Role Hierarchy
1. **Admin**: Full platform access (member management, event CRUD, resource curation, forum moderation, system settings).
2. **Mentor**: Special access to mentor dashboard, session booking requests, mentee communication, and resource publishing.
3. **Member**: Authenticated community member with access to events RSVP, profile editing, forum posting, resource library, and mentorship requests.
4. **Visitor / Public**: Unauthenticated guest access to public landing, about, public events calendar, and registration.
