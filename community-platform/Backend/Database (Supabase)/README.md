# Supabase Database Schema

Relational database model designed for PostgreSQL hosted on Supabase.

## Primary Tables
- `profiles`: Extended user profile details linked to `auth.users`.
- `events`: Community workshops, meetups, and webinars.
- `event_registrations`: Member RSVP records, tickets, and check-in status.
- `resources`: Learning tutorials, guides, and download links.
- `forum_topics`: Community discussion threads categorized by topic.
- `forum_replies`: Member replies and discussion comments.
- `mentorship_sessions`: 1-on-1 mentorship appointments and feedback.
- `announcements`: Site-wide broadcast banners and notices.
